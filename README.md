## How I work

- **Hypothesis before code.** If it does not fit in one sentence, it is not a hypothesis.
- **Validation in time.** Train/test split along the time axis, walk-forward, purging. The number of tried variants is reported.
- **Costs always.** A backtest without spread, slippage and fees is fiction.
- **Failures are documented.** The list of ideas that did not work is the most informative part of a repository.
- **Reproducible.** Notebooks explore, modules compute, tests prove.
